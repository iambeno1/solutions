# ganti versi php di xampp
langkah-langkah: <br>
1. rename folder apche dan php sesuai dengan versinya saat ini. misal saat ini saya menggunakan php 8 maka saya bisa mengubah nama foldernya menjadi "apache 8" dan "php 8"
2. selanjutnya itu kunjungi website <a href="https://sourceforge.net/projects/xampp/files/XAMPP%20Windows/">ini</a>  dan cari versi yang anda inginkan kemudian didownload
3. setelah versi php yg dinginkan sudah dipilih, selanjutnya masuk dan download zip xampp yang ini:
   ![image](https://github.com/user-attachments/assets/f63da971-4f8a-4eb5-a56d-6a5d0eea166e)
4. setelah download selesai, lakukan unzip file tersebut dan salin folder "apache" dan "php" lalu masukan ke folder C:\xampp\. Disini harus dipastikan terlebih dahulu bahwa poin nomor 1 telah dilakukan dengan benar.
